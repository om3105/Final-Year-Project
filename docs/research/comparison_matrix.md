# Systematic comparison matrix

YES means explicit support in a reviewed source; PARTIAL means indirect or limited support; NO means an explicit incompatible architecture or scope; NOT REPORTED means the evidence was not established. A review may discuss a method without training it. Early detection is YES only for a future/prognostic outcome, while cross-sectional early-stage tasks are PARTIAL. Multi-dataset capability is not synonymous with external patient-level validation. This is a methods map, not a performance ranking.
