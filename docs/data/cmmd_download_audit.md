# CMMD acquisition and initial suitability audit

**30 September 2026.** The cancer task selected in ADR-013 is benign-versus-malignant breast lesion classification. [TCIA's CMMD collection](https://www.cancerimagingarchive.net/collection/cmmd/) is public under CC BY 4.0 and requires dataset citation and compliance with [TCIA's data-use policy](https://www.cancerimagingarchive.net/data-usage-policies-and-restrictions/). It describes 1,775 patients, 5,202 DICOM images and about 22.86 GB of imaging. The official clinical XLSX and TCIA manifest were downloaded into the Git-ignored `data/raw/cmmd/` directory. The public [NCI Imaging Data Commons](https://portal.imaging.datacommons.cancer.gov/collections/cmmd/) series index and cloud manifest were saved in Git-ignored `data/metadata/cmmd/`; DICOM transfer and validation status must be checked locally before use. These files are **not** part of the repository and are not to be uploaded to Git.

The official clinical workbook contains **1,872 breast-side rows for 1,775 unique patient IDs**. Its columns are `ID1`, `LeftRight`, `Age`, `number`, `abnormality`, `classification` and `subtype`. Row-level `classification` counts are 556 benign and 1,316 malignant; these are **not patient-level class counts**. At the patient level, 465 have only benign rows, 1,280 only malignant rows, and 30 have one row of each class. `subtype` is present for 749 rows and is a post-diagnosis tumor attribute. `number` is constant in the downloaded sheet. The original collection notes that D2 patient IDs represent malignant cases and that laterality must be interpreted carefully. IDC reports one series for each of the 1,775 patient IDs, with the same D1/D2 prefix counts as the workbook. Exact image-to-breast-side mapping and duplicate image review are pending.

**Suitability finding:** Age is the only obvious independent pre-diagnosis clinical variable in this workbook. `abnormality` describes the image; `classification` is the target; `subtype` is downstream of malignancy. `LeftRight` is laterality metadata, not independent clinical history. A clinical Transformer is therefore **not justified for CMMD on the currently downloaded fields**. CMMD can support an image-only lesion malignancy experiment and a limited age-plus-image fusion comparison, subject to patient-level label audit. It does not establish a rich image-plus-clinical model. Do not add image-derived or target-defining fields as clinical inputs to make the architecture look multimodal.

**Download status at user clarification:** the full DICOM transfer was stopped when the user clarified they wanted a suitability answer. The clinical workbook and manifests are complete; approximately 1,022 of 5,202 image files were locally present at that point. Treat the image folder as **incomplete** and do not train or test from it without resuming and verifying the whole cohort. All downloaded data remain Git-ignored.

Before training: verify all DICOM transfer counts and hashes where possible, join series to workbook IDs using IDC metadata, resolve duplicate pixels identified on the TCIA collection page, construct participant-disjoint splits, and report patient/breast-level class balance, missingness, age distributions and image QC. Keep all patient-level data in ignored local or appropriately governed cloud storage. The user has not authorized application implementation; no model has been trained.
